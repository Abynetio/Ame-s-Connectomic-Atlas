# Ame's Connectomic Atlas

A 3D, projection-level atlas of the human central nervous system for neuroanatomy teaching
(medical school level and above). For each region it shows where the region is, what it is
called, which tract carries its output, and where that output ends.

**Status:** planning. See [PLAN.md](PLAN.md) for data sources, licensing, architecture and milestones.

Not intended for clinical or surgical-planning use.
